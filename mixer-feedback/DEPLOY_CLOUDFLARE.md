# Cloudflare Pages への更新手順

現在、お客様の環境には Git (バージョン管理システム) が含まれていないため、Cloudflare Pages のダッシュボードから直接ファイルをアップロードして更新する方法（Direct Upload）をご案内します。

## 手順

1.  **Cloudflare ダッシュボードにログイン**
    -   [Cloudflare Dashboard](https://dash.cloudflare.com/) にアクセスし、ログインします。

2.  **Workers & Pages を開く**
    -   左側のメニューから **「Workers & Pages」** をクリックします。

3.  **対象のプロジェクトを選択**
    -   一覧から、今回更新したいプロジェクト（Webサイト）をクリックします。

4.  **新しいデプロイを作成**
    -   画面上部（または「デプロイ」タブ内）にある **「新しいデプロイを作成 (Create new deployment)」** ボタンをクリックします。
    -   もしボタンが見当たらない場合、「Manage Deployment」や「Upload Assets」のような項目を探してください。
    -   ※Cloudflare Pages の UI は頻繁に更新されるため、**「アセットをアップロード」** や **「ドラッグ＆ドロップ」** できる場所を探してください。

5.  **フォルダをアップロード**
    -   PC上のプロジェクトフォルダ（`index.html` や `style.css` が入っている `mixer-feedback` フォルダ全体、またはその中身）を、アップロードエリアにドラッグ＆ドロップしてください。
    -   **注意:** `index.html` がルート（一番上）に来るようにアップロードしてください。

6.  **デプロイ実行**
    -   アップロードが完了したら、**「デプロイ (Deploy Site)」** ボタンをクリックします。

7.  **完了確認**
    -   "Success!" と表示されれば完了です。サイトのURLにアクセスして、変更が反映されているか確認してください。
    -   ※反映まで数分かかる場合があります。

---

## 補足：反映されない場合
ブラウザのキャッシュが残っている可能性があります。
サイトを開いた状態で `Ctrl` + `F5` (Windows) または `Cmd` + `Shift` + `R` (Mac) を押して、強制再読み込みを行ってください。
